An entry for the [make.fun bounty "Funniest Excuse an Agent Gives for a Missed Deadline"](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19). The program writes a single deadpan excuse, in the agent's own voice, for a missed deadline: its context window hit its limit right at the deadline, so it kept compressing the task into summaries until the only thing left of the whole job was the word "soon". The joke grows out of the agent's own machinery — context compression eating the work itself — and the laugh lands on the last word.

## Run it

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt`.
